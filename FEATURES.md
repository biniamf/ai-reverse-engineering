# Feature List

[English](FEATURES.md) | [Русский](FEATURES.ru.md)

## Current Features

### Analysis And Chat

- Flask web UI for uploads, job selection, chat, and recovered artifacts.
- Headless Ghidra REST integration.
- Upload native binaries and track analysis jobs.
- Stream AI responses through server-sent events.
- Show tool-call activity while the assistant works.
- Save chat history per job.
- Ask for imports, strings, functions, xrefs, pseudocode, and artifact searches.
- Resolve function requests by name or address.
- Preserve the original OpenAI-compatible workflow.

### Model Providers

- Local Ollama mode for private/offline reverse engineering.
- Hosted OpenAI mode.
- Custom OpenAI-compatible endpoint mode.
- Shared LLM configuration for chat and recovery passes.
- Runtime sidebar showing active provider, model, LLM endpoint, and Ghidra
  endpoint.
- Web `Settings` panel for changing AI provider and translator configuration at
  runtime.

### Recovery Artifacts

- Deterministic recovery index built from Ghidra artifacts.
- `recovery_manifest.json` with generated-file descriptions and counters.
- `recovered_symbols.h` for conservative symbols and layout candidates.
- `recovered_stubs.cpp` for recovered storage/global stubs.
- `recovered_functions.cpp` for selected Ghidra pseudocode drafts.
- Optional `recovered_types.h` generated by AI type/class recovery.
- Optional `recovered_renames.json` generated by AI rename recovery.
- Non-destructive `.renamed.*` variants when a safe rename map exists.
- Dynamic module and function pointer hints.
- Helper-name inference.
- MSVC decorated owner/class candidate extraction.
- Structure layout candidates from pointer/offset patterns.
- Class layout candidates from constructor/vtable patterns.
- VC++ 2003-oriented reconstruction prompts for legacy Windows code.

### Analysis UX

- Dedicated `Analysis` tab.
- Syntax-highlighted editor for C/C++, headers, JSON, Markdown, and text.
- Recovery progress cards for Ghidra, artifacts, recovery, and AI passes.
- Symbol Map with original name, recovered name, address, signature, and status.
- Symbol filters: `All`, `Draft`, `Renamed`, `Raw`, `Missing`.
- Click-to-jump from Symbol Map into the generated source editor.
- Clickable function names and large hex addresses inside the source editor.
- Function inspector with signature, source file, callers, inferred calls, and
  related strings.
- Inspector-to-chat buttons for explanation, rename review, and VC++ 2003
  reconstruction prompts.
- Highlighted destination line in the editor gutter.
- Collapsible analysis navigator.
- Editor `Wrap` mode for long decompiler lines.
- Editor `Focus` mode for large files, with `Esc` exit.
- Compact file stats: language, line count, and file size.
- Custom dark scrollbars and polished loading states.
- Branded favicon and sidebar icon.
- Drag-and-drop upload zone with selected-file preview.

### Translation

- Optional LibreTranslate support.
- Optional custom JSON network translator support.
- Per-message chat translation button.
- Automatic target selection: Russian to English, other text to Russian.
- Markdown/code-aware translation protection for code blocks, inline code,
  symbols, and hex addresses.

### Local Storage And Cleanup

- Local runtime directories for Ghidra data, chats, recovery indexes, and
  recovered files.
- Local job deletion and cleanup.
- Deleted-job tracking to hide locally removed jobs.
- `.gitignore` excludes generated data, logs, virtual environments, and caches.
- Dockerfile for the Flask app.
- Docker Compose stack for Flask, Ghidra REST, and the offline LibreTranslate
  image.
- Runtime log directory with ignored rotating Flask/Werkzeug logs.

## Not Implemented Yet

- Health dashboard for Ghidra, LLM, and translator connectivity.
- Markdown/PDF recovery report export.
- Compile-ready generated source.
- APK analysis pipeline with jadx/apktool.
- Multi-user auth, queues, quotas, billing, and production deployment topology.
